# WorkNext

WorkNext is an AI-powered workforce platform designed to help reduce unemployment and underemployment by connecting job seekers with career guidance, resume-building tools, skill development resources, local job opportunities, and recruiter services.

## Features

- Landing Page
- Login & Sign Up
- User Dashboard
- User Profile
- Resume Builder
- Local Job Finder
- Employment Dashboard
- Community & Mentorship
- Recruiter Dashboard
- Responsive Design
- Dark/Light Mode
- Multilingual UI
- Accessibility Features

## Tech Stack

- React
- Vite
- Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
```
